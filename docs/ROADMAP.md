# 开发阶段

## 首版已交付能力

| 阶段 | 实现 |
| --- | --- |
| M0 | 前后端骨架、锁文件、冻结数据库迁移、Docker 配置、账号与角色 |
| M1 | 上传、索引目录扫描、原件存储、库内去重、缩略图、虚拟化浏览 |
| M2 | EXIF、A1111、NovelAI / 隐写、ComfyUI、Sidecar、冲突记录与重新解析 |
| M3 | AST / DSL / 可视化筛选、字段查询、错误提示、分面、游标分页、智能集合 |
| M4 | 灯箱、个人评分收藏备注、共享标签和集合、批量整理、复制、下载与导出 |
| M5 | 监控＋补扫、内置字典、规则、任务租约与恢复、回收站 |
| M6 | 单元与真实数据库集成、组件与浏览器端到端测试、十万资产基准、数据库恢复验证、运维文档 |

M6 已包含实际 Compose 启动、容器备份恢复与受限资源的 HTTP 基准；数据集和环境边界以 `VALIDATION.md` 为准。

## 已知首版边界

- ComfyUI 参数提取支持唯一 KSampler / KSamplerAdvanced、CLIPTextEncode、CheckpointLoader 与 LoRA 直连链。自定义节点、多采样分支和动态提示词只保存原图并告警。
- Prompt 权重解析支持常见语法，不是各生成器完整提示词求值器；原文始终保留。
- 内置分类字典覆盖少量常用英文词；更多分类通过管理员规则添加，不声称自动识别图像实际内容。
- 上传单批最多 200 个文件，前端分批提交；不支持断点续传。普通标签列表返回最多 2000 项，后续可增加分页探索。
- 批量选择作用于已载入结果，最多 1000 个 ID；没有隐式“对十万条搜索结果全部执行”的操作。
- 不提供永久删除按钮或自动清理策略；避免索引库原件被应用删除。
