# v0.2 使用说明

## 批量下载

在图库勾选图片（可按 Shift 连选），点击底部 **批量下载 ZIP → 打包并下载 ZIP**。打包完成后自动下载，也能在后台任务重新下载。

默认包含原图和动作参考附件，可勾选同时导出生成参数、共享提示词分组和自己的备注。单次最多 1000 张；文件名保留原名并添加资产标识，缺失文件在 `manifest.json` 中注明。导出包仅创建者可下载。

## 管理员完整备份

进入 **设置 → 系统备份**，填写时间节点备注后点击 **创建备份并下载**。默认包含全部数据库内容、托管原图、动作参考附件、缩略图、暂存、导出包、可读取的索引库原图及关联 Sidecar。

数据库包括所有账号、密码哈希、私人备注、评分、收藏、标签、规则、集合、任务和原始元数据。备份含所有成员的数据，仅管理员可以创建、查看、下载、取消或重试。

备份期间允许浏览，数据编辑暂时返回“只读”提示；完成或取消后恢复编辑。每个文件记录 SHA-256。索引源文件缺失会在备份历史和清单中提示；内容与入库哈希不同或打包过程中发生变化时任务失败，重新扫描后可重试。

历史备份 ZIP 不递归放入新备份，`.env`、部署配置及数据库服务器角色配置需另行保管。ZIP 为 PostgreSQL custom dump 与原图打包，图片不二次压缩。压缩包不加密，应存放在受控位置。备份按需创建，不自动清理，磁盘需容纳完整副本。恢复步骤见 [运维文档](OPERATIONS.md)。

## NovelAI 角色和动作参考图

新增解析 `v4_prompt` / `v4_negative_prompt` 角色提示词、负向提示词、坐标、顺序设置；兼容 `characterPrompts`，普通元信息和 alpha 隐写均适用。详情“生成参数”按角色展示并分别复制，完整参数保留角色数组和未识别字段。

旧图片可在 **设置 → 元信息解析器 → 更新已有 NovelAI 角色信息** 批量重新解析。该操作保留原始历史、人工标签、私人状态及提示词分组。`prompt.tag:` / `negative.tag:` 可匹配基础提示词及角色 token；文本包含 `prompt:` / `negative:` 仍表示基础 Prompt。

在详情 **参考图** 页添加 PNG / JPEG / WebP，可写说明、选择角色，支持多附件、查看、下载、移除。附件与图片一起共享；移除只隐藏关联记录，备份仍保存历史附件文件。附件不会修改原始图片，也不会凭元信息自动还原不存在的参考图片。

## 彩色提示词分组

在详情 **标签 → 提示词分组** 选择来源（基础／角色、正向／负向），点击词条后新建分组或移入已有分组。可改组名、颜色和排列顺序，点 **保存分组** 后所有成员共享。

勾选需要的组并点 **复制选中分组**，按当前来源的组顺序拼接；也可单独复制一组。保留词条原文、权重和转义，不混合正负向提示词。最多 32 组；同一词条仅分配给一组。并发编辑使用版本检查，冲突时保留本地修改并提示刷新，避免覆盖他人的整理。

## 删除共享标签

- **从当前图片移除人工标签**：详情“标签”中点击该标签旁的删除图标；或图库多选后填写标签名，点击“移除人工标签”。其他图片的标签不受影响。
- **全局删除标签**：管理员打开“标签探索”，筛选标签，点击“删除”并确认。所有图片上的同名标签关系被移除，自动规则和字典也不再重新添加。以后手工再次添加同名标签可解除禁用。

普通成员可添加、移除图片上的人工标签，全局删除仅管理员可用。

## 本地 Git

仓库使用 `main` 分支，保留 v0.1 基线提交和 v0.2 功能提交。`.env`、数据目录、备份和测试输出不进入 Git。尚未配置远程仓库或推送。
