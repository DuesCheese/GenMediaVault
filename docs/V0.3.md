# v0.3：本地 Tag 翻译

## 图片页

打开图片详情 → **标签 → 提示词翻译**。开关默认关闭；开启后，基础提示词、角色提示词、正负向词条及手工分组中的词条使用共享对照表显示中文。

- 命中词表才翻译，缺失时保留原文；不会调用外部翻译服务。
- 匹配忽略大小写，空格与下划线等价，支持转义括号。
- 保留 `(...)`、`{...}`、`[...]`、SD 数值权重及 NovelAI `1.5::...::`；翻译后的显示不会写回原始元信息或人工分组。
- 悬停查看英文原词和词库分类。**复制分组始终复制英文原文及权重**，用于继续生成。

## 菜单中的 Tag 翻译

所有登录成员可搜索、浏览分类和复制英文 Tag。管理员可新增、编辑、删除中英对照及其所属分类。每页 50 条，不一次加载完整词表。

- 英文支持片段搜索，例如 `white`、`hair`、`WHITE_H`。
- 中文支持包含搜索；2–12 个汉字也支持按字符顺序模糊查询，例如 **白发 → 白色头发、蓝眼 → 蓝色眼睛**。连续命中优先显示。
- 使用分类下拉框或点击词条的分类筛选，支持一个词条属于多个分类。
- 编辑时分类每行一个，也可从已有分类中选择。翻译可留空，在“只看未翻译”中补齐。
- 重复英文别名会被拒绝；并发编辑及删除检查版本，避免覆盖别人的修改。
- 删除的是翻译对照，不删除图片标签、Prompt 或人工分组；之后图片显示原文。重启不会重新补回删除的对照。

词库分类和图片中的彩色人工分组分别保存，浏览参考分类不会改写已有人工整理。
