# v0.4：标签探索与全局分组

## 从翻译词库同步

管理员打开 **Tag 翻译 → 同步为标签**，将整个词库按分类合并到标签探索。按钮不受当前搜索或分类筛选影响。

- 同名组复用已有组，保留已有颜色和人工添加的 Tag；重复同步不会重复创建组或 Tag。
- 同一 Tag 可属于多个组。没有分类的词条归入“未分组”。
- 同步为显式合并：翻译表和全局组分别维护；之后修改翻译表的分类，需要再次点击同步。全局组的修改不会反向改写翻译表。
- 在全局组删除的关系，如果仍存在于翻译表，**再次点击同步会重新加入**。翻译词条删除不会自动清理全局组。

## 将图片分组设为全局组

1. 打开图片 → **标签**，选择提示词后新建普通分组，并填写组名、颜色。
2. 点击“删除分组”右侧的 **全局分组**。这会保存当前图片的分组修改；标签探索中没有同名组就创建，有则合并 Tag。
3. 之后打开其他图片时，会按全局组自动匹配提示词，包括已有图片和后续导入图片，不需要重新解析。

匹配忽略大小写，空格与下划线等价，支持权重括号及 NovelAI 权重。图片展示与复制仍保留原始英文和权重。普通人工分组优先，选择词条建立普通分组不会删除词库关系。多组共用同一词条时，复制选中组会对同一来源中的同一个词条去重；已保存的组顺序保留。

在图片的全局组中增删词条后，点击 **保存分组**，变更才同步到标签探索和其他图片。仅更新本次增删的关系，不会用一张图片的词条覆盖整个组。

删除图片中的某个全局组并保存，会从该全局组移除此图包含的 Tag；组内其他 Tag 保留。删除的是归组关系，原始提示词不会删除。全局组名称和颜色统一在标签探索中修改。

基础／角色、正向／负向提示词分别显示；词库关系共享，所以从一个来源删除某个全局 Tag，其他来源也会同步取消该关系。编辑期间如有其他成员更新词库或图片分组，保存会提示冲突，可放弃本地修改并刷新。

## 标签探索

- 左侧搜索支持组名、英文 Tag 和中文翻译；点组名查看其成员。
- 组内可搜索、新增、编辑、移除 Tag，每页 50 条；支持复制英文和查找包含该 Tag 的图片。
- 全局组可新建、改名、换颜色；普通成员可以整理组与成员，管理员可删除整个组及执行翻译词库同步。
- 原有的生成器／规则／人工共享标签保留在页面下方 **图片共享标签** 折叠区。
- 全局组和成员关系纳入完整备份；导出包含元信息时，保存当前有效分组。
