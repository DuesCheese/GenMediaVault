# GenMedia Vault v0.6.0

- 上传默认进入私人空间，可批量公开／取消公开；图片标记上传者。
- `admin` 成为超级管理员，可浏览所有私人空间并修改上传者。
- 支持 1 天、7 天、30 天限时分享图链，匿名只读查看、复制参数、下载原图与参考图；可随时撤销。
- 管理员设置页新增 GitHub 在线更新：校验发布包、升级前备份、执行迁移、健康检查和失败回滚。
- 加强搜索、媒体直链、附件、任务与导出的权限隔离；更新窗口暂停写入和后台任务。

下载 `GenMediaVault-v0.6.0-Windows.zip`，完整解压后运行 `GenMediaVault.exe`。需要 Docker Desktop Linux 容器；首次构建需要联网。

**从 v0.5 首次升级**：先备份，将 ZIP 覆盖到原目录，保留 `.env` 和 Docker 数据卷，再启动服务。已有图片归属 admin 并保留公开状态，新上传默认私有。后续版本可通过设置页在线更新。

分享地址必须是访问者可连接的本站地址；localhost 地址不能供其他设备使用。发布包不包含私人图片、数据库或凭据。

详细说明见 [v0.6 使用与升级指南](https://github.com/DuesCheese/GenMediaVault/blob/main/docs/V0.6.md)。
