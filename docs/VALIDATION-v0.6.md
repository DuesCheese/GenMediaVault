## 权限及迁移

实际 PostgreSQL 验证普通用户不能读取他人私有图片的搜索结果、计数、模型建议、标签统计、原图、缩略图、工作流和附件，也不能借批量接口或导出绕过。普通管理员不具备超级管理员的图库读取权限，不能改动超级管理员账号。

验证同库同上传者去重、不同上传者分别建档、上传者转移冲突、转移后旧账号失去访问权，索引库补扫保留已修改的上传者。已公开图片仍保留在上传者空间；取消公开撤销相关分享并阻止无权限用户下载旧导出包。

独立数据库先迁移至 0004，写入旧版用户／资产后升级至 0005：旧图上传者为 admin、保留公开状态，admin 角色为 superadmin。全量测试也覆盖空库初始化。

分享覆盖 1／7／30 天、过期、撤销、取消公开、转移上传者及附件越界访问；匿名访问者只有明确定义的读接口。浏览器检查只读页没有输入、评分或整理控件，原图下载可用。

## 实际更新控制器

在独立 `gmv-v06-test` Compose 项目运行真实控制器，使用待发布源码模拟下一版本附件，实际执行镜像构建、停止 app/worker、pg_dump、替换源码、数据库迁移和健康检查。原项目名与原索引目录挂载保留，.env 未被替换。

再次注入新版本启动失败，实际执行 pg_restore、恢复旧源码、旧镜像重启；应用恢复健康。升级前备份保留在控制卷。发布包路径、哈希及版本拒绝逻辑有独立测试。更新窗口禁止应用写入及 worker 领取任务，避免回滚丢失新写入。

远程下载来源固定为官方 GitHub 仓库；模拟附件仅用于隔离验收，未加入生产代码的网络替代路径。
